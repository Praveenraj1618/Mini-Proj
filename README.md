# Legal AI document review

## Expanded document review: English, Tamil and Hindi

The multilingual workflow adds document-family selection, Tamil/Hindi explanations,
multilingual retrieval and explicit OCR language selection. See
[setup, document coverage and validation limits](docs/multilingual_document_review.md)
before running it. Update existing embedding/OCR settings and re-upload documents.
This expands the pipeline; it does not establish legal or translation accuracy.
